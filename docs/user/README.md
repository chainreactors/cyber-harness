# 使用者指南

[文档首页](../README.md) · 前置：[基本概念](../concepts.md)

aiscan 提供两种主要的工作方式。Agent 接受自然语言任务，由模型选择工具并根据结果继续工作；扫描命令执行明确的扫描器或规则流水线。CLI 和 Web 提供不同的操作界面，底层能力由所用发行版决定。

## 开始使用

[快速开始](../getting-started.md)介绍安装、模型配置和第一次运行。先用一个本地只读任务确认模型与工具可用，再根据需要进入扫描或 Web。`aiscan` 包含核心安全工具，`aiscan-full` 额外包含 Web、浏览器、被动测绘和深度爬取。

## Agent 与会话

[Agent](../agent.md)介绍交互模式、一次性任务、工具执行和目标评估。一次任务可以包含多轮模型请求；多次追问则通过会话形成连续工作。

[会话与上下文](sessions.md)进一步解释消息如何进入正在运行的任务，以及历史、压缩、记录与恢复的关系。理解这些行为后，可以更准确地控制长任务，并保留后续工作需要的证据。

## 工具与知识

[工具](tools.md)介绍文件、命令、后台任务、代理和浏览器的使用方式。[Skills 与知识](knowledge.md)介绍模型怎样获得领域方法，以及怎样加入自己的 Skill。工具提供实际执行能力，知识说明如何使用它们，两者共同影响任务表现。

## 扫描与协作

[安全扫描](../scan.md)介绍从输入目标到服务、指纹和发现的流水线，以及 AI 验证与输出。[Web 与协作](web.md)介绍工作台、远程节点、本地子 Agent 和 IOA 消息空间。

完整参数按需查阅[配置与命令参考](../reference.md)。教程里的命令以当前源码为准；使用发行版时，应阅读对应 Git tag 的文档。
