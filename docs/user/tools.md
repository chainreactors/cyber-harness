# 工具

[使用者指南](README.md) · 前一篇：[会话与上下文](sessions.md) · 下一篇：[Skills 与知识](knowledge.md)

工具是 Agent 读取和改变环境的方式。模型看到工具名称、说明和参数结构，再请求执行；aiscan 返回实际结果，模型据此继续工作。可用集合取决于发行版及已安装扩展，运行时可用 `/status` 查看。

## 文件与命令

文件工具支持读取、查找和修改内容，`bash` 支持命令式工作。工作目录决定相对路径的起点，宿主权限决定进程实际可以访问的环境。会话本身不提供容器或文件系统隔离。

`bash` 既可以执行宿主上的程序，也可以调用 aiscan 注册的命令。例如 `gogo`、`spray` 和 `scan` 可以直接调用内置扫描器，无需在 PATH 中另放一个同名程序；普通外部命令仍要求系统安装对应工具。

交互模式的 `!` 前缀直接执行命令，适合查看帮助或手动完成明确的操作：

```text
aiscan> !gogo -h
aiscan> !tmux ls
```

内置命令和外部命令可以通过执行适配层组成管道。不同命令有自己的参数作用域，例如 Agent 的 `-p` 表示 prompt，gogo 的 `-p` 表示端口。参数细节见[命令参考](../reference.md)。

## 后台任务

较长的命令可以在等待一段时间后转入后台，使 Agent 继续处理其他工作。以下是模型调用 `bash` 时的参数形态：

```json
{"command":"某个长时间运行的命令","wait":5,"timeout":120}
```

`wait` 表示此次工具调用在前台等待的秒数。5 秒后尚未结束，工具返回后台 session ID，命令继续运行；`wait: 0` 或省略则等待完成。`timeout` 是命令的总运行期限，转入后台后仍生效；省略使用默认 600 秒，显式设为 0 表示不设置总期限。

完成结果会送回 Agent 会话，运行期间也可通过 `tmux` 查看输出、发送交互输入或停止任务。这是 aiscan 自己的工作管理命令，不要求系统安装 tmux。

```text
aiscan> !tmux ls
aiscan> !tmux kill -t <session-id>
```

长输出可能只在模型上下文中保留部分内容。需要查看较早输出时使用工具返回的读取提示，完整管理语法见[终端命令说明](../../agent/skills/cyber/okf/runtime/tmux.md)。远程 API 的前台执行入口有独立契约，不能把 Agent 的后台等待参数等同于所有入口的行为。

## 网络与代理

aiscan 的工具网络出口由本地代理 Hub 管理。`--proxy` 设置初始上游，Agent 可以通过 `proxy` 命令管理和切换节点；`mitm` 用于查看捕获的请求和响应。稳定的本地地址使工具可以复用路由配置。

```sh
aiscan scan -i http://127.0.0.1:3000 --verify=off --proxy socks5://127.0.0.1:1080
```

内置客户端接收代理配置，外部程序通过代理与 CA 环境变量接入。忽略这些变量的程序不一定经过 Hub；上游切换也不会把已经建立的 TCP 连接迁移到另一出口。

HTTPS 捕获依赖客户端信任 Hub CA。`--mitm=false` 关闭捕获，保留路由。模型 API 使用独立的 `--llm-proxy`，与扫描工具的出口分别配置。协议、节点管理和捕获限制见[代理参考](../reference.md#代理proxy)。

## 浏览器与外部工具

full 版的浏览器支持页面导航、交互、截图和网络捕获。持久浏览器会话保留多步交互状态，适合需要登录或 JavaScript 渲染的页面；它的状态与 Agent 的对话历史不同，恢复聊天记录不会恢复旧浏览器实例。具体命令见[浏览器说明](../../agent/skills/cyber/okf/easm/playwright.md)。

Arsenal 管理外部安全工具，并将安装目录加入子进程 PATH。安装后的工具仍需要满足平台与运行依赖。原生桌面录屏是另外的可选构建，见 [record](../record.md)。

## 搜索与资源

`web_search` 获取网络搜索结果，`fetch` 读取 URL 内容。搜索优先使用支持该能力的 Provider，必要时使用已配置的 Tavily；没有可用后端时会失败。搜索结果提供线索，具体判断仍需读取和核实来源。

Cyberhub 面向已经加载的指纹和 POC 资源，支持按指纹、CVE 等查询关联。它与公共网络搜索的用途不同。资源配置及扫描器用法见[参考手册](../reference.md#cyberhub-资源)。
