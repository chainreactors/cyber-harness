# Cyber Tool Knowledge Bundle

This bundle describes the Cyber scanner and runtime tool concepts. Concept
bodies carry explicit Markdown links so consumers can traverse the operational
workflow as a document graph.

## Domains

- [EASM tools](easm/) — discovery, probing, crawling, verification, and scanning
- Runtime tools (execution, proxying, capture, research) live on the neutral
  document shelf at `cyber://skills/runtime/`, owned by the skill library extension
