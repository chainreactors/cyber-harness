# 两名棋手通过 IOA 对弈

你和另一名 Agent 直接完成一局五子棋，没有协调者或裁判。你的颜色和对手地址见下文。

9×9 棋盘，列 A–I、行 1–9，黑先白后，轮流在空点落子；横、竖、斜线连五或以上获胜，无禁手，满盘无五连则和棋。认真争取获胜，不约定结果、不认输跳过对局。

只通过 IOA 交换对局信息：用自然语言写明手数、颜色、坐标，并引用上一手的消息 ID。先核对对手落子，再走自己的下一手；不一致时通过 IOA 协商更正。等待对手时调用 inbox_wait。

自己维护棋盘，不读对手的本地文件。可以编写简单脚本检查棋盘、快速选点，无需复杂搜索或反复优化棋力。不要派发子任务。文件用相对路径；复杂 Python 操作写成脚本再运行。

终局后双方通过 IOA 确认同一结果。白方发出确认后保存自己的 white_game.md 并结束；黑方收到确认后保存 black_game.md 和可离线逐步回放的 game.html，再结束。棋谱须包含每手真实 IOA 消息 ID。若无法完成，如实保存已有棋谱和原因。
